# 本地模型管理器 1.2.1

字幕助手 2.6.5.2 的 Windows 当前用户配套。复用现有 E 盘 Python 环境与兼容模型；不会在安装或打开设置时下载权重、转写或重启服务。

## 安装与升级

1. 等当前识别及酒馆等共享任务结束，在字幕助手设置 → 语音识别 → 语音识别服务中点击“停止服务”，确认服务已停止。这是停止语音识别，不是退出管理器连接。
2. 关闭设置页，运行 `E:\Work\日语视频学习插件\outputs\退出本地模型管理器.lnk`，释放管理器连接并暂时阻止浏览器自动拉起。此快捷方式本身不会停止识别服务。
3. 运行更新包里的 `Install-Connection.cmd`（完整包也提供根目录“升级本地识别配套.cmd”）。已安装时自动沿用注册目录及扩展 ID，不需再次复制 ID。原文件夹名即使仍是 `model-manager-1.0.0` 也不需要移动或重装。没有注册的新安装才要求输入 ID，默认目录为 `model-manager-1.2.1`。
4. 运行 `E:\Work\日语视频学习插件\outputs\恢复本地模型管理器连接.lnk`，重新加载浏览器扩展，打开设置，重新连接管理器并点击“启动服务”，再刷新视频页。

安装器自动备份代码，保留模型、管理状态与服务记录；仍有运行中的管理器服务时拒绝覆盖，不会替你停止共享任务。仅更新扩展、未更新并重新启动本配套时，开头补识别尚未生效。原独立启动脚本仍保持原样，应从插件设置启动新配套服务。

安装仅注册当前 Windows 用户的 Edge/Chrome，绑定明确的扩展 ID，无需管理员权限。检测到占用、不同浏览器注册不同配套或链接目录时拒绝覆盖。

## 模型目录与文件

“联网检查可用模型”只读取 [faster-whisper 官方映射](https://github.com/SYSTRAN/faster-whisper/blob/master/faster_whisper/utils.py) 与各仓库元数据。可筛选日语可用、英语可用、全部或已安装。目录显示名字、文件合计、语言、用途定位与来源；体积不等于实际识别质量。部分来源失败会显示数量，已有安装保留。

下载由用户单独点击，固定到仓库提交并校验每个运行时文件：大权重采用 SHA256，小文件支持 Git blob SHA1。目录更新不会重新解释已安装模型。下载取消、失败或连接关闭不会替换旧模型；不执行远端 Python 或其他代码。

“导入已有模型”选择包含 `model.bin`、`config.json`、`tokenizer.json` 及词表的 CTranslate2 Whisper 物理目录，检查结构后原位复用，不复制权重。语言能力不明的目录可登记，但不能用于该原语言；英语专用模型不能用于日语。small、medium 原位复用，均支持日语和英语。选择下载位置只影响以后的下载。

删除先预览准确目录、运行时文件合计大小和将保留的其他文件，再要求确认。默认模型、原启动方式默认和服务仍可能使用的模型不可删。确认 token 短期单次有效，执行前重新核对文件身份，拒绝链接、重解析点和重叠路径。复用模型也能明确删除，因此请核对预览；同目录其他文件保留。

## 服务与默认模型

“设为默认”用于以后的字幕识别，不提交音频。新安装目录需“应用模型并重启”后被已运行服务识别。已有共享服务可以直接复用；首次接管会短暂重启，需要用户先暂停酒馆等其他使用者，程序再核验身份与两次空闲状态。管理器服务发现其他使用者后保护 15 分钟；活动或排队期间不能停止。

“原启动方式默认模型”是独立操作，明确确认后先备份原 `settings.json`，再只改默认模型，不重启正在运行的服务。原启动脚本保持不变。

解除连接运行安装目录的 `Uninstall-Connection.cmd`，恢复最初注册，保留模型与配置；后续已替换的连接不会被覆盖。恢复原启动方式前，先安全停止管理器服务，再运行原启动脚本。

## 验证边界

线上目录验证是元数据检查，不代表所有目录模型都实际下载或推理通过。文件下载/取消使用小型夹具；真实 Windows 程序、普通路径与 junction、隔离浏览器连接分别验证。用户 18766 服务不被本轮开发重启，未下载大型权重。系统文件夹选择对话框及用户服务首次接管未实际执行。

## 开头补识别

仅对从 0 秒开始的初始窗口、日语/英语、至少 8 秒音频检查。已有首句在 3–8 秒之间，并且前 2.5 秒内开始有人声、缺口内累计至少 1 秒人声时，复用同一已加载模型再识别前 8 秒一次。置信度、句尾完整性、人声覆盖率与重复文本检查通过后，仅补入首句之前、不与原字幕重叠的内容。后续窗口和正常开头不重复识别。

界面不增加按钮；检查结果（含未补出内容）随字幕缓存。新扩展仅淘汰缺少版本标记的首窗口缓存，人工/AI 校对记录不删除。VAD、置信度均是启发式；长静音、无完整候选或不可靠候选会跳过，不保证找回所有漏句。音乐与人声混合仍可能误判，本轮只验证了真实新闻音频、纯静音和合成音调。
