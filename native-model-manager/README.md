# 本地模型管理器 1.1.0

语言学习助手 2.6.5.0 的 Windows 当前用户配套。复用现有 E 盘 Python 环境与兼容模型；不会在安装或打开设置时下载权重、转写或重启服务。

## 安装与升级

1. 保持原扩展加载目录升级，复制新版设置页显示的扩展 ID。
2. **关闭设置页，在扩展管理页点击“重新加载”，暂不重新打开设置。** 后台连接也需要释放，只关闭设置页可能仍占用旧配套。
3. 解压新配套，运行 `Install-Connection.cmd` 并粘贴 ID。已有注册时自动找到原配套目录，备份代码后升级，保留管理状态、服务记录、模型和原注册备份。没有旧注册时默认安装到 `E:\Work\日语视频学习插件\local-asr\model-manager-1.1.0`。
4. 重新打开设置，点击“刷新状态”。不需要停止原识别服务。`Install-Connection.ps1 -WhatIf -ExtensionId 实际ID` 可预览。

安装仅注册当前 Windows 用户的 Edge/Chrome，绑定明确的扩展 ID，无需管理员权限。检测到占用、不同浏览器注册不同配套或链接目录时拒绝覆盖。

## 模型目录与文件

“联网检查可用模型”只读取 [faster-whisper 官方映射](https://github.com/SYSTRAN/faster-whisper/blob/master/faster_whisper/utils.py) 与各仓库元数据。默认筛选日语适用模型，可查看全部或已安装。目录显示名字、文件合计、语言、用途定位与来源；体积不等于实际识别质量。部分来源失败会显示数量，已有安装保留。

下载由用户单独点击，固定到仓库提交并校验每个运行时文件：大权重采用 SHA256，小文件支持 Git blob SHA1。目录更新不会重新解释已安装模型。下载取消、失败或连接关闭不会替换旧模型；不执行远端 Python 或其他代码。

“导入已有模型”选择包含 `model.bin`、`config.json`、`tokenizer.json` 及词表的 CTranslate2 Whisper 物理目录，检查结构后原位复用，不复制权重。无法确认支持日语的目录可登记，但不能设为日语默认或启动。选择下载位置只影响以后的下载。

删除先预览准确目录、运行时文件合计大小和将保留的其他文件，再要求确认。默认模型、原启动方式默认和服务仍可能使用的模型不可删。确认 token 短期单次有效，执行前重新核对文件身份，拒绝链接、重解析点和重叠路径。复用模型也能明确删除，因此请核对预览；同目录其他文件保留。

## 服务与默认模型

“设为默认”用于以后的字幕识别，不提交音频。新安装目录需“应用模型并重启”后被已运行服务识别。已有共享服务可以直接复用；首次接管会短暂重启，需要用户先暂停酒馆等其他使用者，程序再核验身份与两次空闲状态。管理器服务发现其他使用者后保护 15 分钟；活动或排队期间不能停止。

“原启动方式默认模型”是独立操作，明确确认后先备份原 `settings.json`，再只改默认模型，不重启正在运行的服务。原启动脚本保持不变。

解除连接运行安装目录的 `Uninstall-Connection.cmd`，恢复最初注册，保留模型与配置；后续已替换的连接不会被覆盖。恢复原启动方式前，先安全停止管理器服务，再运行原启动脚本。
