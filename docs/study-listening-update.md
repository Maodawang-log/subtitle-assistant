# 字幕助手：精听中文与双语开关修复

“揭示中文”现在显示在右侧“当前句”卡片里、原文下方。即使原文隐藏，也可以单独查看中文。进入跟读页即可看到当前句卡片，无需先启动录音或授权麦克风。

有现成译文时直接显示；没有时只按点击翻译当前一句，卡片内显示加载状态或错误，可重试。单句揭示不会开启全局双语，也不会在全局双语关闭时往画面或字幕列表加入中文。换句、退出精听、修改字幕／接口或关双语后，旧请求不能回填到当前卡片。

精听导航顺序为“听上一句、重听本句、听下一句”，首尾对应按钮禁用。只有“开始精听”进入模式；普通重听或前后句播放不会偷偷隐藏字幕。精听重听保留已揭示内容，换句才重新隐藏。退出时恢复普通字幕规则，并撤销精听自己的句末暂停；不会自动播放、跳时间或清掉已有录音。

主操作栏在普通窗口和全屏中统一为“上句、下句、暂停、重播”，保留其余按钮、字号和播放器比例。全屏跟读页在侧栏保留当前句卡片；其他页面继续使用原来的全屏跟读位置，复用同一个录音播放器。

关闭“双语字幕”会立即清除插件在画面和字幕列表中显示的中文，同时撤回当前已揭示的中文、停止自动翻译并使旧响应失效。之后再明确点击“揭示中文”，只在当前句卡片显示。视频本身烧录的字幕不属于插件字幕层，不会被移除。

## 更新

1. 双击 **更新字幕助手.cmd**。程序先备份，再更新原加载目录，并显示备份路径。
2. 在 Edge／Chrome 扩展管理页重新加载原来的“字幕助手”。
3. 刷新视频页及已经打开的设置页。

默认目录为 `E:\Work\日语视频学习插件\outputs\biliscript-japanese-study-2.6.5.1`，内部版本为 2.6.5.2。其他加载目录可通过 `-ExistingDirectory` 指定 outputs 中现有的字幕助手目录。

版本号保持 2.6.5.2。本包基于“收藏星标与分类修复”，保留收藏状态、分类、视频长期保存、字幕、生词、人工校对和复习资料。无需删除扩展、重填 Key、更新本地配套或下载模型。制作更新包时没有自动覆盖当前安装。

需要回退时双击 **恢复更新前界面.cmd**，输入本次更新显示的备份路径，然后重新加载扩展并刷新视频页。回退仅恢复扩展文件，浏览器里已经保存的数据保留。
