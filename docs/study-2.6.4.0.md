# 语言学习助手 2.6.4.0

这一版接着 2.6.3.6 的页面兼容修复，完成字幕双开关、字幕拖选讲解、单词/生词本和本地模型管理。原有相同释义的异写合并保留。

## 升级

关闭正在进行的学习，在浏览器扩展管理页查看原扩展的加载目录。运行同目录交付的 `升级原加载目录-2.6.4.0.cmd`，粘贴该目录；它先备份和校验，再复制新版文件。回到扩展管理页，重新加载原扩展并刷新视频页。

保持原加载路径，不要删除原扩展。原 API Key、词典和生词仍在原浏览器存储中。新包新增本地连接权限；首次本地模型管理还需下面的一次配套连接。没有自动覆盖你的日常安装，也没有替你启用这一连接。

手动升级也可将 `biliscript-japanese-study-2.6.4.0.zip` 解压后，把其中的扩展文件复制到原加载目录。先备份原目录。回退时把升级脚本给出的备份复制回原路径，再重新加载扩展。

## 字幕与查词

- 每个视频/P 默认关闭。在播放器右下原生控制栏点击“开启字幕”，优先使用日语 CC，没有时使用已有本地识别流程。
- “双语字幕”默认关闭。打开后显示已有中文，并限量翻译当前和下一句；关闭它会取消翻译，日语字幕继续工作。关闭字幕或换视频会取消关联任务。
- 单击日语单词，进入“单词”看本地释义，不自动调用文字接口。可手动点“AI词义与变形”。
- 按住鼠标跨词拖选，松开后自动打开所选片段的讲解，同时在“单词”准备相关释义。播放器字幕、全屏和右栏都支持；注音不会混入所选原文。“本句讲解”仍解释整句。
- 同一片段可复用讲解缓存；请求失败或补填 Key 后，可重新拖选重试。未配置时显示“去设置”，本地查词仍可使用。
- 单词旁星标可保存/取消；“生词本”单独显示，展开条目看完整释义和新保存的原句、视频/P、时间链接。旧记录继续可用，没有来源的旧记录不会被补造来源。

文字接口继续支持自填 OpenAI 兼容 Base URL、模型名和 Key。DeepSeek Key 直接填设置页即可；本次没有读取或使用你的 Key，也没有发起付费请求。本地识别、字幕导入、句控和录音不依赖文字接口 Key。

## 本地模型管理：第一次连接

1. 解压 `biliscript-local-model-manager-1.0.0.zip`，打开新版扩展设置页，在“本地模型与服务”复制扩展 ID。
2. 双击配套包的 `Install-Connection.cmd`，粘贴该 ID。安装器只为当前 Windows 用户注册 Edge/Chrome 连接，无需管理员权限；默认文件位置在 `E:\Work\日语视频学习插件\local-asr\model-manager-1.0.0`。
3. 回设置页点“刷新状态”。已有 small/medium 会原位复用，原来选择的 medium 会保留。打开设置不会下载模型、提交音频或重启服务。
4. 已运行的旧服务可以直接继续使用。如需以后在设置页启停，先暂停本地酒馆等其他识别使用者，再点“首次接管现有服务”。该按钮会核验服务身份及空闲状态，确认后短暂重启；无法确认或有任务时拒绝接管。

以后可在设置页选未来下载位置、下载/取消、设默认模型及安全启停。选目录不会移动原模型；下载只用固定版本并校验完整性，全部通过才启用。默认模型与服务当前驻留模型分别显示；新安装的模型目录需“应用模型并重启”后生效。

正在识别或排队时不能停止；管理服务发现其他使用者后保护 15 分钟。原始服务没有其他应用的使用记录，因此首次接管需先由你暂停其他使用者。

解除连接运行安装目录的 `Uninstall-Connection.cmd`。它恢复安装前的注册，保留模型、安装文件和浏览器设置。若要恢复原启动方式，先在设置页安全停止管理器服务，再使用原有启动脚本。原脚本一直保留。
