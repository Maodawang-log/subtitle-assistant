# 视频收藏入口简化

视频面板只保留一个“收藏视频”按钮。收藏后显示“已收藏”，已取得的字幕、总结和对话长期保留，后续取得的字幕与学习记录也继续保存。收藏不触发全片识别或额外模型请求；部分字幕仍按实际范围显示。

删除视频面板的“长期保存资料”和“收藏当前句”按钮。句子收藏沿用字幕列表的星标，生词收藏沿用单词星标。

旧版长期保存的资料会作为已收藏视频显示。旧版只保存视频信息的收藏继续保留，并复用已经缓存或之后正常取得的字幕，不另行转写。日语、英语和分P仍然隔离。

再次点击“已收藏”可取消收藏。资料转为受容量限制的临时缓存；字幕句子、生词、校对和复习记录保留。收藏列表和设置里的取消入口使用相同逻辑，不留下另一个独立的长期保存开关。

本轮仅调整收藏与保存入口。精听按钮的调查结论尚未实施。
