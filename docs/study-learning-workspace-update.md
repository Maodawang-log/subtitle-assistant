# 字幕助手：视频学习与复习更新

适用于现有字幕助手 2.6.5.2。本包在原加载目录更新扩展文件，版本号不变。保留上一轮开头补识别、重复字幕修复、人工校对和设置清理。

## 更新

1. 保存正在输入的字幕修改。双击本包的 **更新字幕助手.cmd**。
2. 看到完成和备份位置后，在 Edge / Chrome 扩展管理页找到原来的「字幕助手」，点击**重新加载**。
3. 刷新 B 站视频页；已经打开的设置页也刷新一次。

默认加载目录仍为 `E:\Work\日语视频学习插件\outputs\biliscript-japanese-study-2.6.5.1`。它的文件夹名未改，内部版本为 2.6.5.2。无需删除扩展、重新填写 Key 或重新加载为新扩展。

本轮不更新本地识别配套，不运行连接安装器，不需要为了本包停止共享服务。旧更新包和 outputs 中退出/恢复管理器的快捷方式均保留。

如需回退，双击 **恢复更新前界面.cmd**，粘贴更新时显示的备份目录，再重新加载扩展和刷新页面。回退只恢复扩展文件；新收藏、复习状态、长期资料和校对记录仍留在浏览器中，旧界面可能不显示新功能数据，重装本包后恢复可见。

## 入口与用法

- **字幕**：顶部为“导入字幕 / 导出字幕 / 跟随当前句 / 全部校对”。每句人工校对与 AI 校对等宽；星标收藏该句。
- **视频**：总结与章节、视频问答、视频学习清单、视频/句子收藏、长期保存和整批校对记录。点击出处时间播放原句。精选表达与语法可收藏例句，或打开既有单词面板查词、收藏。
- **生词本**：继续用原星标收藏单词。“开始复习”只出到期词；先遮住释义，显示答案后选记得或忘了。首次记得安排一天后，之后逐渐延长；忘了安排十分钟后。状态保存在本机，原有导出继续可用。
- **跟读**：上方新增精听。开始时隐藏助手的字幕，听完当前句自动暂停，可以揭示原文/中文、重听、下一句或跟读。已有中文可揭示；需要新增中文译文时先开启双语字幕。视频画面自带的烧录字幕仍会显示。录音沿用原功能，没有发音评分。

## 总结与问答的范围

“总结已取得字幕”只处理点击时已有的日语或英语原文，用中文输出。不因标题猜剧情，不分析画面，不默认联网搜索。每条生成要点、章节、表达及回答段落必须附合法原句编号；页面使用原始字幕显示引文和时间，不采用模型自报时间戳。

播放窗口有空缺时标为部分字幕，并显示不连续范围。处理过的静音窗口属于已收集范围，不能用“有台词的时段”替代处理范围。字幕轨和手动导入的完整性无法单凭首尾时间证明，因此明确标注未核实。试看只收集实际允许播放的范围，不会冒充原视频全片。

“收集全片并总结”是单独的主动操作：复用已有本地识别服务，按窗口补齐允许的音轨，沿用同一个队列，跳过已处理窗口，可以停止。不会新增模型或重复启动服务。收集结束仍会显示实际范围；这一步本身不等于长期保存。

长字幕分段处理后分层汇总，不经过旧短句接口的 4500 字截断。总结最终保留精简的全局章节和表达。多轮历史有单独预算，原句证据不截断。成功分段保留临时缓存；失败和停止后不会自行重试付费请求。

缓存按视频/分P、CID、语言、有效字幕修订、接口和模型隔离。新增不重叠的后续字幕不会强制取消已开始的快照任务；原范围被改写、切视频/语言或停止字幕会取消旧任务。结果保留原范围，资料更新后标记过期，不自动重新收费。

## 全部校对

点击一次启动当前已取得字幕的批量 AI 校对，显示范围与进度；完成后统一采用，无需再点“全部采用”。已经修改的句子会跳过，包含旧版无法区分来源的修改，以保护人工结果。

结构化返回必须逐句匹配本次编号，不允许增删句子、改时间戳或增加其他字段。不确定的句子保留原文。新字幕只要不改动本次原范围，可以继续到达，不被这批覆盖。

请求中可以停止；另一标签页的人工修改也会阻止过期结果采用。最后的统一保存阶段会明确显示，并暂时禁用停止和逐句校对按钮；此时已进入保存，完成后通过视频面板的“校对记录”整批撤销。撤销只回退仍属于该批的修改，之后的人工修改保留，即使文字恰好相同也按编辑标记区分。

校对保持时间轴，重新分词/注音，使旧翻译失效；只有双语开关开启时才请求所需新翻译。

## 保存与清理

视频收藏仅保存元数据，不触发整片识别。句子收藏保存 BV、分P、语言、原句和时间，可以回看/重听。识别或 AI 生成建议不会自动收藏。

新取得/导入的字幕、未长期保存的总结与对话默认属于临时资料。手动点击“长期保存资料”后，字幕与学习记录进入保留区。旧版已经导入的字幕维持原保存方式，原生词、人工/AI 校对和复习状态保留。

设置新增“资料与缓存”，可查看占用、设置 1–256 MiB 临时上限（默认 16 MiB）、清理临时缓存和删除选中的长期资料。临时窗口、临时完整资料及文字结果合并计算限额，按最近使用时间淘汰。长期资料、收藏、校对/整批撤销记录、复习状态不参与自动清理。模型和词典不在此限额内。

对话只保存实际引用原句的快照和紧凑的版本摘要，不在每轮复制整片字幕。单条资料超过临时限额时会提示未保存，结果仍在当前页面；可增大容量或手动长期保存。刷新字幕会重新取来源，普通重开优先恢复已保存资料。
