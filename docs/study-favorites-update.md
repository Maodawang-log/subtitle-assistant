# 字幕助手：收藏星标与分类修复

字幕旁的 ☆ 现在是收藏开关。保存成功后变为高亮 ★，再次点击取消；保存期间会暂时禁用同一句的收藏按钮。失败时保留原状态，并在当前面板顶部显示原因。

星标会从已保存的收藏恢复，重建字幕列表、重新打开页面或清理临时缓存后仍然有效。从收藏列表移除句子，或在总结出处、学习例句中收藏／取消，其他入口也会同步。其他页面发来的较新收藏状态不会被旧请求的回执覆盖。

原来的“视频与句子收藏”区域分成“视频收藏”和“句子收藏”，分别显示数量。视频显示标题和打开入口；句子显示时间、原句、所属视频和回听入口。

保留原有视频收藏、句子收藏、生词、人工校对、学习记录和复习记录，继续使用原来的收藏数据。收藏一句不会收藏整部视频，也不会触发全片识别。“收藏视频”继续长期保存已取得的字幕及后续学习记录；取消视频收藏后，相关资料转回临时缓存。

## 更新方法

1. 打开此更新包所在文件夹，双击 **更新字幕助手.cmd**。程序会备份后更新原加载目录，并显示备份路径。
2. 在 Edge／Chrome 的扩展管理页，重新加载原来的“字幕助手”。
3. 刷新 B 站视频页及已经打开的设置页。

默认更新目录为 `E:\Work\日语视频学习插件\outputs\biliscript-japanese-study-2.6.5.1`，其内部版本为 2.6.5.2。使用其他加载目录时，可通过 `-ExistingDirectory` 指定 outputs 下现有的字幕助手目录。

无需删除扩展、重填 Key、更新本地配套或下载模型。本包仅更新九个扩展界面／程序文件，版本号仍为 2.6.5.2。制作更新包时未自动覆盖当前加载目录。

需要回退时双击 **恢复更新前界面.cmd**，粘贴本次更新显示的备份路径，再重新加载扩展、刷新视频页。回退仅还原扩展文件，已经保存的收藏及学习数据仍保留。

## 验证范围

自动测试覆盖保存／取消、保存失败、重复点击、旧数据、刷新恢复、清理缓存、引用入口同步、跨页面消息及延迟回执。保留原有“收藏入口简化”的视频保存逻辑。

隔离 Edge 检查使用真实扩展、后台和点击交互，页面、字幕、音频及 AI／ASR 返回均为测试数据；验证了失败提示、星标变化、页面重载、分组、窄侧栏和相关学习流程。没有调用付费接口、真实识别服务或麦克风，未将这些测试等同于用户真实 B 站页面验收。

更新、重复更新、备份和回滚在独立测试目录验证。具体计数、截图、构建哈希及校验结果见 verification 文件夹。本轮未修改语言选择器、精听逻辑、本地模型、共享识别服务或连接快捷方式。
