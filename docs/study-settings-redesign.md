# 字幕助手 · 设置页改版体验包

适用于 **2.6.5.2**，按热更新方式交付，版本号不变。

## 体验新版

关闭原设置页，双击本包的 **更新设置页.cmd**，然后重新打开设置页。无需卸载扩展，也不必重启语音识别服务。

更新目标是此前保留的原加载目录：

`E:\Work\日语视频学习插件\outputs\biliscript-japanese-study-2.6.5.1`

这个目录中的扩展实际版本已经是 2.6.5.2。脚本会检查扩展名称和版本，先备份，再只替换 `study/options.html`、`options.css`、`options.js`、`options.js.map` 四个页面文件。不会修改版本号、播放器脚本、模型、词典、API Key 或管理器配置。不要把本更新包当作完整扩展加载。

如果当前加载目录不同，可以通过 PowerShell 指定原目录：

```powershell
.\Apply-SettingsUpdate.ps1 -ExistingDirectory 'E:\Work\日语视频学习插件\outputs\实际加载目录'
```

## 这次改善

- 设置分为“字幕与外观、语音识别、翻译与讲解、离线词典”四页。页面切换保留未保存的输入，浏览器后退可返回上一分类。
- 字幕预览跟随日语／英语选择，自动字号保留为默认；选择手动模式后才出现字号滑块。字号、颜色更改即时保存，播放器行为不变。
- 管理器连接与语音识别服务分别显示状态。未连接不再误报为服务停止；服务忙碌、被其他应用使用、端口被占用时，显示相应状态与可用操作。
- 只有打开“语音识别”才检查管理器；离开该分类暂停轮询。连接失败后停止自动重试，恢复后点击“重新连接”。outputs 中的退出、恢复管理器快捷方式均保留原位。
- 识别模型只在一个下拉框选择，更改后独立保存。去掉每张卡片重复的“设为默认”，与接口保存分开。新导入模型尚未被运行中服务识别时，明确提示下一步。
- 模型卡片等宽等高；文件路径、来源、保存位置和原启动脚本默认收进详情。原启动默认仍是独立、需确认的操作，不会跟随插件识别模型自动改写。
- 翻译接口单独保存，空 Key 保留已保存值。显示按钮只显示新输入，不会读回旧 Key；移除已保存 Key 需明确确认。诊断与兼容选项折叠。
- 词典保留多语言默认选择、安装与离线查询，隐藏重复的完整安装清单；查询支持 Enter，删除前显示词典名称并确认。

## 验证边界

相关自动测试与类型检查、实际构建页面的 Edge 宽窄屏和交互检查均记录在本包 `verification` 中。浏览器检查包括真实鼠标导航、键盘导航与查词、设置保存、连接失败／忙碌等状态以及 375–1500 像素宽度。

连接状态与模型目录使用隔离测试数据，词典查词使用浏览器临时数据库中的小型测试词条。未实际接管、启停或重启用户共享服务，未下载权重、请求付费接口或读取用户浏览器中的 Key。这些检查不等同于用户日常浏览器及真实服务的端到端验收。

## 回退

更新完成会显示备份目录。双击 **恢复旧设置页.cmd**，粘贴该目录即可恢复四个旧页面文件，再刷新设置页。

备份位于 `E:\Work\日语视频学习插件\snapshots\settings-redesign-*`。恢复脚本会核对备份及当前文件；如果文件后来又被更新，会停止覆盖，避免误回退其他改动。
