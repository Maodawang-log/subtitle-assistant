# 字幕助手 · 设置页与图标入口更新

基于 2.6.5.2 的累计热更新，版本号不变。已包含上一份设置页改版，无需依次安装两个更新包。

## 使用新版

1. 关闭设置页，双击 **更新字幕助手.cmd**。脚本会检查原加载目录、校验文件并自动备份。
2. 在浏览器扩展管理页，对原来的“字幕助手”点击 **重新加载**。
3. 刷新已打开的 B 站视频页和设置页。

默认更新此前保留的加载目录：`E:\Work\日语视频学习插件\outputs\biliscript-japanese-study-2.6.5.1`。该目录内的实际版本为 2.6.5.2。不要卸载扩展，不要将本增量包作为完整扩展加载。

若加载目录不同，可运行：

```powershell
.\Apply-UIUpdate.ps1 -ExistingDirectory 'E:\Work\日语视频学习插件\outputs\实际加载目录'
```

## 图标与播放器入口

- 删除注入 B 站播放器控制栏的“开启字幕 / 关闭字幕”按钮，以及它的专用节点、样式和挂载逻辑。
- B 站原生 CC 按钮、右侧助手面板的开启／关闭字幕按钮、已有全屏学习工具栏继续保留。不恢复视频下方的旧入口。
- 在支持的 B 站视频页点击浏览器工具栏的字幕助手图标，呼出该页助手。仍需点击面板内“开启字幕”才获取字幕或识别；翻译仍由双语字幕开关控制。
- 其他页面点击图标，打开设置页。
- 视频页刚开始加载、内容脚本尚未就绪时，保留本次打开意图并等待，不误跳设置页。图标上的省略号表示等待；超过 20 秒仍未就绪时显示提示，刷新视频页后可再次点击。页面已跳转或标签页已关闭时放弃旧意图。

支持范围与现有扩展入口保持一致：主站 BV／av 视频路径、语言前缀视频路径，以及带有效 bvid 的稍后再看播放页。番剧页、搜索页等不属于本扩展当前视频支持范围，点击图标会打开设置。

## 已合并的设置页改善

设置分为“字幕与外观、语音识别、翻译与讲解、离线词典”四页。管理器连接与识别服务分别显示状态；模型只保留一处选择并独立保存；模型卡片统一排版，文件路径、旧启动默认和诊断收进详情。接口保存与本地设置分离，词典删除前确认，查词支持 Enter。

字幕仍默认手动开启；字号仍默认跟随播放器，并保留手动设置。outputs 中的退出、恢复管理器快捷方式保持原位。本次没有排查或重启已经恢复正常的共享识别服务。
