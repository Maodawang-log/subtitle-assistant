# 字幕助手：精听显示开关修复

精听中的两个按钮现在可以反复开关，互不影响：

- **揭示原文／隐藏原文**：只改变原文显示，保持播放位置、暂停状态和精听模式。
- **揭示中文／隐藏中文**：只改变当前句卡片的中文显示。隐藏不会删除已经取得的译文，再显示直接复用，不重复请求，也不会打开全局双语。

按钮文字、选中颜色及辅助技术状态同步。中文翻译期间仍可点击“隐藏中文”取消显示，晚到的结果不会重新出现。失败时，当前句卡片显示原因，按钮恢复“揭示中文”，点一次即可重试。

重听保留当前显示状态，换句重新隐藏；退出精听及关闭双语仍按上一版规则处理。保留精听前后句、主栏顺序、全局双语关闭、录音保留和收藏状态／分类修复。本次不调整布局。

## 更新

1. 双击 **更新字幕助手.cmd**，程序会备份后更新原加载目录，并显示备份路径。
2. 在 Edge／Chrome 扩展管理页重新加载原来的“字幕助手”。
3. 刷新视频页及已经打开的设置页。

默认目录为 `E:\Work\日语视频学习插件\outputs\biliscript-japanese-study-2.6.5.1`，内部版本仍为 2.6.5.2。其他目录可通过 `-ExistingDirectory` 指定 outputs 内的现有字幕助手加载目录。

无需删除扩展、重填 Key、更新本地配套或下载模型。制作更新包时未自动覆盖当前安装，字幕、收藏、生词、人工校对和复习资料均保留。

回退时双击 **恢复更新前界面.cmd**，输入本次更新显示的备份路径，随后重新加载扩展、刷新页面。回退只还原扩展文件，已保存的数据保留。
