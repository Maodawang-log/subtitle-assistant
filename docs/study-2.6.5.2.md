# 字幕助手 2.6.5.2

支持日语、英语视频原文字幕，沿用现有播放器、中文翻译、查词和跟读布局。文字接口仍可自填 OpenAI 兼容地址、模型和 Key；无需现在配置。

## 使用

1. 点击播放器「开启字幕」或浏览器扩展图标，先打开字幕面板。
2. 在「原语言」选择日语或英语，再点击面板「开启字幕」。优先读取对应CC；没有对应轨时使用本地识别。旁边「自动选择日语/英语」仍是字幕轨选择。
3. 开启「双语字幕」后才翻译当前及下一句；讲解、校对仍按按钮手动请求。切换原语言会关闭当前字幕并取消旧任务，重新开启后生效。
4. 「设置 → 默认原语言」用于新视频，侧栏选择仅影响当前视频。离线英语查词需要在既有词典管理中安装或选择英语词典；日语、英语收藏分别显示，旧收藏仍属于日语。

字幕字号默认随实际播放器大小调整。「设置 → 字幕外观」可改为手动；原来保存的字号和颜色会保留，自动模式不会覆盖手动字号。设置会同步到已打开的视频页。普通工具栏保持完整文字和正常高度，在846–850 CSS像素宽度仍可单行显示。

## 升级浏览器扩展

保留原扩展及加载目录，运行随包 `升级原加载目录-2.6.5.2.cmd`，粘贴扩展管理页显示的原目录。脚本先完整备份并核对，再更新文件；支持2.6.3.1至2.6.5.1。随后在扩展管理页重新加载原扩展，刷新视频页。不要删除原扩展，以便沿用已有设置、Key、词典和收藏。

包目录是 `biliscript-japanese-study-2.6.5.2`，保留旧目录命名以方便升级。文件名与内部存储键不影响新可见名「字幕助手」。备份位置由脚本显示；回退时关闭字幕，将备份全部文件复制回原加载目录，再重新加载扩展。开发交付没有直接改动你的安装。

## 升级本地配套至1.2.0

英语CC和导入字幕不依赖后端升级。**无英语CC时的英语本地识别需要新版配套服务**；旧服务的窗口接口只接受日语，不能仅更新浏览器包。

1. 在新版设置页复制扩展ID，关闭设置页，在扩展管理页重新加载扩展，暂不重新打开设置，以释放旧连接。
2. 解压 `biliscript-local-model-manager-1.2.0.zip`，运行 `Install-Connection.cmd` 并粘贴ID。已有注册会更新原配套目录并自动备份，保留原模型与管理状态。
3. 打开设置、刷新状态。安装过程不会停止运行中的共享服务。要启用新英语窗口功能，请暂停酒馆等其他应用的识别，在空闲时手动点击「首次接管现有服务」或「应用模型并重启」；程序再次检查身份、活动与排队状态后才切换。

现有small/medium都可复用日语和英语，无需重新下载。模型筛选新增「英语可用」；能力未知或不支持当前原语言的模型不能设为默认。识别始终转录原文，中文翻译仍由文字接口完成。

回退配套时先安全停止管理器服务，释放扩展连接，按安装输出的备份恢复配套代码；原始 `local-asr/server.py`、模型和原启动方式保留，可按原方式启动。仅卸载连接不会删除模型。任何共享服务切换都由你手动操作，本轮开发没有重启18766。
