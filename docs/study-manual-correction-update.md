# 字幕助手：人工校对更新

版本保持 2.6.5.2，包含此前设置页改版和扩展图标入口更新。

## 安装

运行「更新字幕助手.cmd」，随后到浏览器扩展管理页重新加载原来的字幕助手，再刷新视频页。默认更新已有 outputs/biliscript-japanese-study-2.6.5.1 加载目录（内部版本须为 2.6.5.2）。安装前自动备份；恢复请运行「恢复更新前界面.cmd」并输入更新时显示的备份目录。

## 使用

每句时间戳下直接显示「人工校对」「AI 校对」。人工校对在右侧原句位置编辑，支持保存、取消、恢复原文；Ctrl+Enter 保存，Esc 取消。日语使用扩展本地词典重新分词并生成假名，英语重新分词而不加假名。时间戳保持不变。

修改独立保存在浏览器本地，按视频分P和原语言隔离；刷新页面后重新开启字幕会恢复。后续识别窗口、原始缓存和过期 AI 校对建议不会覆盖已保存修订。恢复原文只撤销当前句修订。不同浏览器配置或清除扩展数据不共享这些记录。

人工编辑不调用校对 AI。修改后的旧中文译文失效；双语关闭时不请求新翻译，已开启时按原有当前/下一句翻译规则处理。AI 校对仍先展示建议，再由用户采用。

只更新九个界面/入口文件，不改扩展版本、模型、词典、接口 Key 或识别服务，不需要重启识别服务。本包尚未覆盖你的实际安装。

## 验证边界

自动测试覆盖保存、取消、恢复、重新载入、语言/分P隔离、缓存与过期 AI 请求保护。隔离 Edge 中加载真实构建，鼠标/键盘编辑并刷新验证；日语注音使用随扩展分发的本地词典。视频、字幕和接口响应为合成夹具，没有对真实视频或付费接口验收。
