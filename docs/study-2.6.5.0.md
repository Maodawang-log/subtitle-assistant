# 语言学习助手 2.6.5.0

这一版完成普通窗口跟读布局、状态位置、重复字幕修复、字幕外观、单词折叠、模型目录管理和逐句校对。保持每个视频手动开启字幕，双语独立开启，本地查词与原词典、生词记录继续使用。

## 升级扩展

关闭正在进行的学习，在扩展管理页查看原加载目录。运行交付目录中的 `升级原加载目录-2.6.5.0.cmd` 并粘贴该目录；脚本先完整备份与校验，再复制新版。回扩展管理页重新加载原扩展，刷新视频页。支持 2.6.3.1 至 2.6.4.0 原目录。

保持原加载路径，不要删除原扩展，原接口配置、词典和生词在原浏览器存储中继续使用。也可备份后把 `biliscript-japanese-study-2.6.5.0.zip` 内文件复制进原加载目录。回退时复制脚本给出的旧版备份，再重新加载。新交付没有自动覆盖你的日常加载目录。

## 普通窗口、跟读与字幕

开启字幕后，普通窗口保留真实视频、标题、单行句控和右栏。在右栏第五个“跟读”页选择麦克风并录音；打开页只暂停并带入当前句，点击录音才开始。授权后设备列表会更新，选择会记住，设备失效会提示并回到系统默认。可停止、回放、保存录音及听原声。全屏保留原跟读入口，录音器和已录音频在模式间继续使用。

状态在普通窗口右栏顶部、全屏绿色工具条左侧；文字过长可悬停查看完整信息。屏幕较矮时实际可见空间仍受浏览器缩放、站点标题高度等影响。

同一识别窗口的新结果会替换旧结果，修订时间和内容不再叠加成两份字幕。不同时间的真实重复台词保留。窗口增删句时保留仍存在的选中句；选中句被删除或修订后停止旧循环。

字幕字号和颜色在设置页调整，滑杆、数字、预设色与自选颜色即时保存，已打开页面同步应用。恢复默认可一键回到原外观；日文、中文和注音大小保持比例，文字描边保留。

单词卡默认展开，点击词头或三角折叠，可全部展开/折叠。星标仍只保存或取消单词，不会顺带折叠。相同释义的异写合并与生词本独立保留。

## 逐句校对

每句时间下有“校对”。点击后将该句和前后各两句文字发送给你配置的接口，讲解页显示原文、建议和原因。查看建议不会改字幕；点“采用建议”才修改，时间戳保持不变，之后可“恢复原文”或听原声核对。

校对是根据文字上下文作出的建议，并不能证明实际音频说法；没有充分依据会显示未变化或不确定。换视频/P、跳转、相关句子重新识别或修改接口后，旧建议失效。无关的后续窗口完成不会取消当前校对。采用后只让该句旧中文失效；双语关闭时不额外翻译，开启时继续只准备当前及下一句。

文字接口按 OpenAI 兼容格式填写。你计划使用 DeepSeek，暂时无需提供地址、模型或 Key；需要时直接在设置页填写。本地识别、导入字幕、句控和录音不依赖文字接口。本轮没有读取用户 Key 或调用付费服务。

## 本地模型管理器 1.1.0

1. 解压 `biliscript-local-model-manager-1.1.0.zip`，复制扩展设置页里的 ID。
2. **关闭设置页，在扩展管理页重新加载扩展，暂不打开设置。** 这一步释放旧后台连接；不需要停止识别服务。
3. 运行新配套的 `Install-Connection.cmd` 并粘贴 ID。已安装 1.0 的会自动找到原目录，校验备份后更新；保留管理状态、服务归属、模型和原注册备份，失败时恢复原文件。
4. 重新打开设置并刷新状态。首次安装只注册当前 Windows 用户的 Edge/Chrome，无需管理员权限。没有旧注册时默认安装在 E 盘项目的 `local-asr\model-manager-1.1.0`。

“联网检查可用模型”只读取官方映射和仓库元数据，不下载权重；本轮实际查到 17 个去重条目。默认显示支持日语的条目，可切换全部或已安装。大小、语言、用途与来源一起显示，大小不代表实际准确率。网络失败会提示，已有安装保留。

下载需单独点击，固定版本并逐文件校验。选择下载位置只影响以后下载。“导入已有模型”选择兼容 CTranslate2 Whisper 物理文件夹，原位复用，不复制权重；语言未确认的模型不能设为日语默认或启动。已安装模型不会因联网目录版本变化而消失。

删除会先显示准确路径、文件大小和保留的其他文件，再确认。当前默认、原启动默认和运行服务仍可使用的模型受保护。复用的原模型也支持明确删除，请仔细核对路径；取消不会删除。链接目录、路径重叠或确认后文件已变化会拒绝。

“原启动方式默认模型”是独立操作，确认后先备份原设置再只改默认，不重启服务。新安装目录若要用于已运行服务，需要显式接管或“应用模型并重启”。首次接管会短暂重启，需要先暂停酒馆等其他使用者；程序检查服务身份与空闲状态。安装连接与打开设置本身不会接管服务。

卸载连接运行安装目录 `Uninstall-Connection.cmd`，恢复原注册并保留模型、配置及原启动脚本。
