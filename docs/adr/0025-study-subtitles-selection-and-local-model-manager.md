# ADR-0025：按视频开启字幕、选段讲解与本地模型管理
> 状态：部分被取代｜固定目录和仅自有模型删除由 ADR-0026 取代；其余保留，补充 ADR-0020、0022、0023，保留 ADR-0024 的站点接管门槛

用户在 2.6.3.6 页面兼容修复完成后，明确恢复之前讨论的字幕、查词、生词本与本地模型管理迭代。原扩展身份、加载路径、保存的文字接口配置、词典、旧生词和已有识别环境应继续使用。

## 决定

- 每个视频/P 均从关闭开始，忽略历史自动开启设置。播放器原生控制栏内提供“开启字幕”，先取日语 CC，再按既有有界策略识别；“双语字幕”默认关，开启后仅翻译当前与下一句，已有中文直接复用。翻译请求有独立取消通道，关闭双语不停止日文识别，关闭字幕或换视频则取消关联工作。
- 播放器、全屏和右栏的字幕以可选择文本呈现；真正跨词拖选在松开鼠标后立即切到选段讲解，同时准备本地单词释义。单击单词只查本地词典；“本句讲解”保持整句，单词仍有手动“AI词义与变形”。读音不进入所选原文。请求绑定来源与代次，缓存相同片段，失败或补填 Key 后可重新拖选重试。
- “单词”展示词头、原形、读音、词性及原有词典结果，沿用相同释义异写合并。词头星标保存/取消；单独“生词本”默认折叠长释义。新词记录实际原句、视频/P 与时间，旧记录继续读写导出，不补造来源。不引入复习间隔或长期记忆算法。
- 本地管理采用独立 Native Messaging 配套。浏览器设置页是唯一入口，精确扩展来源与固定操作白名单双重校验。配套只注册当前 Windows 用户的 Edge/Chrome，默认安装在 E 盘已有项目内，原启动脚本和权重保持原位。
- 复用已装 small/medium；新下载由固定仓库、revision、逐文件大小和 SHA256 目录限定，验证暂存内容后原子启用。选目录只改变未来下载位置；取消/失败不会替换原模型。只允许删除本管理器所有且未使用、非默认的模型。
- 管理器只停止其可核实拥有的服务，检查 PID 创建时间、固定 Python/脚本路径、管理实例、活动/排队请求与其他使用者保护期。已有旧服务直接复用；首次接管需用户明确确认其他使用者已暂停，核验旧服务身份及两次空闲状态后短暂重启。打开设置或安装连接本身不接管、不下载、不转写。

## 约束与代价

三个界面宿主仍须等 `#app[data-server-rendered]` 消失后才能进入站点树。全屏关闭时隐藏所有插件界面，退出全屏后恢复原生控制栏入口。关闭状态没有额外播放器下方占位。

Native Messaging 首次需要一次本地安装器连接，精确绑定当前解压扩展 ID。换加载目录可能改变 ID，需重新绑定；保持原路径升级可以保留浏览器数据。卸载只恢复本次注册，不删除模型、配置或安装文件。

旧服务没有其他消费者租约，无法仅凭空闲快照证明其他应用以后不会发起请求，因此首次接管保留明确确认。新版管理服务在关闭前通过短期停止意图阻止新请求，并保护近期其他消费者。不能据此宣称任意外部进程都可安全停止。

## 验证范围

`tests/study-*.test.ts` 与 Native review 覆盖字幕开关、异步代次、来源与读音选择、旧生词兼容、设置页授权、下载完整性/取消及真实 EXE 持续消息收发。真实 Edge 隔离配置验证原站导航、推荐图片与评论的冷开/开关/刷新/换视频，以及播放器、右栏、全屏的真实鼠标拖选；文字接口使用明确标识的模拟响应，没有使用用户 Key。

独立端口实际加载已有 small、medium 并安全停止，实际浏览器连接经编译的 Windows 配套并恢复临时注册。用户 18766 服务与原始默认设置未被重启或改写。未下载大模型权重，未在用户日常浏览器安装配套，未实际执行用户服务的首次接管；这些不得写成已经验证完成的用户环境行为。
