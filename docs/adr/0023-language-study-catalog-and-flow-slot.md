# ADR-0023：语言学习助手的词典目录与页面占位
> 状态：有效（2.6.3.4 候选）；补充 ADR-0022 的词典与布局实现，播放范围和跟读约束不变

用户实际页面出现入口遮挡点赞区、操作按钮竖排和状态文字挤入标签区。本版修复这些布局问题，并将可见产品名改为「语言学习助手」，接入最小多语言词典管理。通用名称不等于视频识别已经支持所有语言：自动取轨、形态分词和本地 ASR 仍是日语管线。

## 页面占位

B 站内层播放器位于固定高度的 `playerWrap` 中。控件插在内层播放器之后仍处于该固定高度区域，后续原生按钮不会为控件让位。使用自己的 `biliscript-study-slot`，放在外层播放器之后，与原生操作区共同参与正常文档流。窄屏阅读区也在此占位内；宽屏阅读区继续使用右栏。控件宿主的关键盒模型样式隔离站点的 div 重置，操作组允许整组换行，状态文字在同一卡片内自然撑高。

进入容器全屏时移动原有宿主，隐藏空占位；退出后恢复正常流。重复开启、关闭、挂载均复用相同宿主，不创建第二套按钮。内部 ID、消息、浏览器存储键和数据库名保留，避免可见更名破坏已有设置。

全屏时读取可见的 B 站底部 toast 几何，在其上方保留 12px 间隔；原生登录、试看提示不隐藏、不修改。字幕随工具栏实际位置上移，避免与避让后的按钮重叠。原生提示消失后恢复基础底部间距。复用已有的页面同步周期，不新增轮询或监听器。

## 共存与事务

沿用版本 1 的 IndexedDB 及按 generation 建立的索引。每个词典 ID 指向自己的活动代次；新增 `default:ja` / `default:en` 元数据。旧版日中词典没有语言字段时按可信目录识别，不重新导入。新增日英词典时先保存旧的隐式日语默认值，避免更换用户的查询结果。

语言和解析器由目录绑定，不能由下载元数据伪装。查询在同一个只读事务中选定该语言的默认词典和活动代次，只读取该代次；英语索引用小写，展示保留原拼写。设置页列出全部已安装词典，并分别选择每种语言的默认值。

安装和更新仍由全局 Web Lock 串行化，校验完整包后写临时代次，最后原子切换。清理只移除未提交的暂存代次，保护所有已安装词典。删除在事务中仅删除选中词典的记录和默认标记，随后按同语言目录顺序回退；不清空数据库。取消、校验失败和页面关闭恢复均不改变其他词典或旧的活动代次。

Jitendex 更新检查要求相应发布项目的实际资产和 SHA256；ECDICT 当前目录固定已核验版本，更新按钮明确说明新资源随目录更新，不声称检查到了远程最新 CSV。

## 验证边界

真实 B 站 DOM 用隔离 Edge、手动字幕夹具和关闭自动翻译验证布局，覆盖 700、800、900、1141、1440、2048 像素宽度、长状态、全屏退出及反复开关。原生点赞、投币、收藏的可达性采用命中检测，不提交这些操作。词典使用完整真实资源在隔离扩展数据库验证，不读取用户浏览器凭据。原地升级验证只覆盖私有副本；新目录加载会产生不同身份，不自动迁移旧浏览器存储。
