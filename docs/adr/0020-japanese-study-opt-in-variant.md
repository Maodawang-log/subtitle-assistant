# ADR-0020：日语学习快照按视频显式开启
> 状态：有效（仅本地 Japanese Study 衍生入口）
用户于2026-10-25明确要求：默认学习关闭；每视频手动开启；开启才取字幕/音频/翻译；关闭或换视频停止后续任务。此指示覆盖上游ADR-0017在本衍生入口中的“进页即抓且不加开关”行为。上游原入口和该ADR正文保留，不改坏其既有语义。
本地快照使用独立study内容入口和SW，静态复用上游B站元数据/字幕列表处理和音轨获取，避免启动原全片预抓/自动概览。无日文CC时调用本机有界音频窗口服务：30秒片、当前位置加下一片，边界不超过当前位置后60秒，串行识别。真正音频字节由服务按HTTP Range裁片，不将HTMLMediaElement.buffered当音频。
关闭/切视频/跳转取消相应请求和后续排队；缓存只保存文本及资源/模型身份，不保存Cookie或音轨签名URL。翻译只当前/下一句，可关闭；Key用户自行设置。不把文字ASR当发音评分。
