# ADR-0027：保留原生播放器比例与可读句控
> 状态：有效｜2.6.5.1；取代 ADR-0026 中普通窗口强制调整原生尺寸及微缩单行控制的实现方向，其余功能保持

用户将 2.6.5.0 实际画面与已认可的普通窗口概念图对照后指出：播放器外框被拉宽而内部画面与弹幕栏没有同步，页面缺少左右留白，按钮缩成难以辨认的小图标。此前“标题、视频、按钮同屏”与工具栏高度的机械断言不能作为视觉验收。

## 决定

- 不再修改 B 站播放器、视频、左右栏或父容器的宽高、flex、display、object-fit。删除普通模式尺寸整形组件。保留站点原生居中与留白，字幕覆盖层继续沿用实际视频位置，合法的原生素材留黑不做拉伸处理。
- 学习控制条仍在原生播放器外的独立流式位置，按钮用完整文字、14px 字号、38px 高度。宽窗口自然一排，窄窗口允许换行与页面滚动，不通过缩字或压缩播放器追求全部同屏。普通模式下方不重复显示跟读按钮；状态继续在右栏标题行。
- 跟读页沿用同一录音节点与状态，仅调整正常模式的当前句卡片、麦克风行、主操作及“原声／我的录音”层次。概念图中的新音量计或额外播放功能不在本轮范围内。新增说明和分区标签在全屏隐藏，全屏操作顺序与现有布局保持。
- 挂载继续等待站点 SSR 接管，站点尚未完成接管时不改原站树。右栏存在且有实际可见宽度时沿用原侧栏，不改变侧栏自身宽度；较窄页面使用既有下置行为。

## 验证

真实浏览器分别记录开启前后的原生播放器、内部视频层、播放控制、弹幕输入条、左右栏的位置与尺寸。视频/原生部件必须保持原尺寸，左右栏只允许因新增学习内容产生自然高度变化；不得新增侧向黑区或改变左右留白。检查 2526×1187、2048×962、1440×900、1366×768 和 1280×720，并将截图与概念图目视对照。

自动检查保留 SSR 门槛、独立流式挂载、完整按钮文字、录音节点/音频跨模式保留等约束；不再使用“工具栏必须不超过52px”或“所有内容必须同屏”的旧标准。站点导航、推荐图片、评论和全屏回归继续作为必要检查。视觉合格不能仅由这些断言替代。
