# ADR-0028：字幕助手的原语言与播放器字号
> 状态：有效｜2.6.5.2；取代0023的可见名称与仅日语管线限制，补充0020显式开启、0027原生布局约束

用户要求保留现有设计与比例，在识别前选择日语或英语，同时修正 Windows 150%、浏览器100%下约846–850 CSS像素工具栏的换行，并提供自动/手动字幕字号。

## 决定

- 可见产品名为「字幕助手」，设置页标题为「设置」。内部存储键、数据库、DOM ID和加载路径不更名。
- 浏览器图标和播放器入口在关闭状态先打开字幕面板，原语言可在第一次取轨/识别之前选择，随后由面板「开启字幕」明确启动。默认日语；设置保存全局默认，当前视频选择仅作临时覆盖。切语言停止全部工作、推进generation、清空字幕/讲解/选段/录音，需重新明确开启。换视频恢复全局默认。
- CC筛选和当前播放器字幕计数分别支持ja/en，保留原音轨绑定、206与SSR接管门槛。没有对应CC时按选中原语言转录；翻译为中文仍通过用户配置的文字接口，Whisper任务始终为transcribe。自动双语仍须用户打开。
- CC/导入修订身份、ASR缓存、AI缓存和收藏身份包含语言。旧导入缓存和旧收藏仅视为日语；同词的日语、英语收藏互不覆盖。英语词界保留空格、标点、缩写，不调用日语形态分词或添加假名。词典管理和既有资源不变。
- 模型目录提供真实ja/en能力。未知能力不能作为该语言默认；已安装旧元数据以本地文件检查补全，保留版本与文件清单。英语专用tokenizer不能因包含日语特殊token而误判多语言。服务在解码前检查实际模型支持语言，禁止Whisper静默改用英语。复用已装small/medium，不复制或下载权重。
- 配套1.2新增ja/en窗口端点及能力声明。安装升级保留运行中共享服务；只有用户在空闲状态手动接管/重启才切换服务代码。开发不停止18766，原始服务文件不改，提供独立升级包和回退说明。
- 普通模式仅在自有工具栏容器宽度不超过900px时减小按钮水平padding与组间gap，保留14px字号、38px高度和完整文字；全屏维持原样。更窄窗口仍可自然换行，不改变原生播放器尺寸。
- 字幕默认auto，按实际覆盖层容器宽高计算20–34px；手动模式保留16–52px固定值。旧size/color没有mode时默认auto，原手动值保留；自动计算不写存储。中文字号与注音比例、阴影保留。复用原250ms同步生命周期，视频替换先卸载旧seeking监听，pagehide清除轮询、动画和存储监听，bfcache恢复重新绑定。

## 验证边界

针对CC、代理、AI提示与缓存、收藏、切换取消、模型能力、真实端点、实际浏览器交互分别验证。真实公开B站页面用于原生几何对照；846/850宽度由仅约束自有工具栏的独立场景复现，不能把1700视口自然布局说成用户的相同窄栏。英语人声样本验证真实已装权重；窗口传输夹具必须与真实B站CDN链路证据分开。所有测试不提交付费接口请求，不把识别文字视为发音评分。
