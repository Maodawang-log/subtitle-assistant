# ADR-0026：紧凑跟读、字幕修订与可更新的本地模型目录
> 状态：部分被取代｜普通窗口尺寸整形与微缩句控由 ADR-0027 取代；其余有效，部分取代 ADR-0025 的固定模型目录及仅自有模型删除规则，保留 ADR-0024 站点接管门槛

用户在 2.6.4.0 基线提交 `e21eac756e9b5436626c37613c4ecee007dd296c` 上授权七项迭代：普通窗口布局及跟读页、状态位置、重复字幕修复、字幕外观、单词折叠、模型目录管理、逐句手动校对。

## 决定

- 普通窗口在站点接管完成后可逆调整真实播放器与右栏尺寸，保留标题、完整视频、单行控制条和右栏。第五个“跟读”页承载现有录音器；进入时暂停并带入当前句，用户点击才申请录音。全屏沿用原录音入口，同一个录音节点与音频在模式间移动。麦克风授权后再枚举设备，记住选择，设备失效回退系统默认并提示。
- 普通窗口状态放右栏标题行，全屏放绿色工具条左侧。单行省略但完整状态可访问；错误显示明确原因。字幕字号、颜色只在设置页修改，独立保存并实时广播，保留注音比例与文字描边。
- 本地识别窗口以视频资源、语言、模型和开始时间确定身份；同窗口新结果替换旧结果，识别时长变化不生成第二份。重叠窗口只保留未被新窗口覆盖的原片段，并保留其身份和修订号。真实不同时间的重复台词保留；旧缓存读取时按相同规则整理。
- 单词卡默认展开，词头按钮单独折叠，各卡与批量折叠状态明确；迟到的查询结果遵守批量状态。星标与折叠独立，相同释义异写合并继续生效。
- 校对仅由每句时间下的按钮启动，请求目标及前后各两句文字。响应严格限制为建议、未变化或不确定与理由，禁止更改时间戳；用户在讲解页明确采用或恢复。绑定视频/P、句子身份、修订、邻句上下文和接口配置代次。相关变化使结果过期，无关的未来识别窗口不撤销当前校对。采用后清除该句中文（含原 CC 匹配）；只在双语开启时按原有当前及下一句规则翻译。文本推测不能作为音频正确性证明。
- Native 配套 1.1.0 按用户点击从 faster-whisper 官方映射及 Hugging Face 仓库元数据更新目录，不执行远端代码。更新只读元数据；下载固定到提交及逐文件摘要，已安装模型冻结安装清单，不随目录刷新改变。语言资料不明确的导入模型可以保留，但不能当作日语默认或启动。
- 兼容物理模型目录可原位导入，不复制权重。删除允许覆盖用户明确选中的复用模型，但必须先返回准确路径、文件与大小，再凭短期单次 token 二次确认；默认模型、旧启动默认、服务仍可能使用的模型、路径重叠及重解析点均受保护。同目录其他文件保留。原启动方式默认只在独立明确按钮确认后备份再修改。
- 配套升级发现已注册目录后在原目录备份更新，保留管理状态、实例归属、服务记录与模型。浏览器连接占用时拒绝覆盖。升级前关闭设置页并重新加载扩展释放后台连接；安装本身不重启原识别服务。

## 验证与边界

自动检查覆盖修订/缓存隔离、校对手动采用恢复、设备回退与录音节点移动、折叠和目录完整性。真实浏览器几何与鼠标交互用于验证普通窗口/全屏和站点生命周期；模拟接口响应不等同于付费服务验收。Windows 配套检查使用私有目录与隔离端口，原 18766 服务及模型保持原位。

在线目录查到的条目代表已验证元数据格式，不代表每个权重均已下载或实际推理。系统目录选择、真实麦克风与付费文字接口只有实际操作后才可记为通过。
